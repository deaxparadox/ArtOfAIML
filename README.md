# AI Engineer Handbook

A production-oriented handbook for Backend, Machine Learning, LLMs, RAG, Agentic AI, MLOps, System Design, and everything required to become a strong AI Engineer.

This repository is built as a long-term reference, not a collection of blog posts or interview notes.

The focus is on understanding concepts deeply, learning how they work in production, and developing engineering intuition.

---

# Who is this for?

This handbook is intended for:

- Backend Engineers transitioning into AI
- ML Engineers who want stronger software engineering skills
- AI Engineers preparing for production systems
- Software Engineers preparing for interviews
- Anyone who prefers understanding concepts rather than memorizing them
